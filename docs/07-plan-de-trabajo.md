## 7.2 Etapas de desarrollo

| Etapa | Actividades | Resultado esperado |
|---|---|---|
| 1. Planeación | Definición del problema, objetivos, alcance y usuarios | Documento inicial del proyecto |
| 2. Análisis | Identificación de requisitos y casos de uso | Requisitos y casos de uso definidos |
| 3. Diseño | Arquitectura del sistema y diseño de pantallas en Figma | Prototipo y arquitectura definidos |
| 4. Desarrollo frontend | Implementación de HTML, CSS y JavaScript | Interfaz funcional |
| 5. Desarrollo backend | Implementación de C# y .NET, y de la API REST | Servidor funcional |
| 6. Base de datos | Diseño e implementación de la persistencia | Base de datos funcional |
| 7. Integración | Conexión entre interfaz, API y base de datos | Sistema integrado |
| 8. Pruebas | Pruebas funcionales y corrección de errores | Versión estable |
| 9. Despliegue | Preparación y publicación de la aplicación | Sistema disponible en el entorno seleccionado |
| 10. Documentación | Manuales, evidencias y presentación | Entrega final del proyecto |

El desarrollo es progresivo: empieza con la planeación y termina con la integración, las pruebas y el despliegue.
